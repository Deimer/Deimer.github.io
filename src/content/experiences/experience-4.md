## About CTI Consulting

**CTI Consulting** is an IT consulting and technology services firm based in Miami, Florida[cite: 1]. The company specializes in delivering custom software solutions, enterprise application integration, and digital transformation initiatives for clients across North and South America.

## Technical Scope & Business Impact

During my time at CTI Consulting, I worked as a Senior Android Developer delivering robust mobile solutions for high-demand business applications[cite: 1]. My work focused on modernizing legacy codebases, implementing Android Architecture Components, and building cross-platform feature modules[cite: 1].

* **Android Architecture Components & Navigation:** Implemented **Clean Architecture** combined with **MVVM** and **AndroidX** libraries[cite: 1]. Integrated **Navigation Component**[cite: 1] to manage single-activity navigation flows smoothly, reducing boilerplate code and preventing fragment lifecycle bugs.
* **Asynchronous Streams & Reactive State:** Handled asynchronous operations and reactive data pipelines using **Kotlin Coroutines and Flow** alongside **RxJava**[cite: 1], ensuring thread-safe execution across background workers and UI rendering layers.
* **Cloud Persistence & Real-time Sync:** Engineered backend integration with Firebase suite, leveraging **Firestore Database**, **Firebase Realtime Database**, and **Firebase Analytics**[cite: 1] to provide real-time user synchronization, dynamic data updates, and behavioral tracking.
* **Dependency Injection & Local Caching:** Configured lightweight dependency injection using **Koin** and **Hilt**[cite: 1] to decouple presentation and domain logic. Managed local persistent storage with **Room Database**[cite: 1] for reliable offline capabilities.
* **Cross-Platform Engineering:** Developed hybrid cross-platform application modules using **Flutter**[cite: 1], enabling code reusability across platforms while maintaining native-like visual performance.
* **Networking & CI/CD Pipelines:** Integrated high-performance RESTful networking using **Retrofit**[cite: 1]. Automated testing, build triggers, and deployment workflows using **GitHub Actions**[cite: 1] for continuous delivery.

## About DedopinWeb

**DedopinWeb** is a software development agency based in Barranquilla, Colombia. The firm specializes in delivering custom website developments, e-commerce applications, and early hybrid/native mobile software solutions for regional commercial businesses.

---

## Technical Scope & Business Impact

At DedopinWeb, I served as a Desarrollador Web y Movil, delivering full-stack web features and hybrid mobile application prototypes.

* **Hybrid & Native Mobile Prototypes:** Developed cross-platform mobile applications using **PhoneGap** alongside native **Android SDK** components, creating responsive client UI layouts and handling offline storage integrations.
* **Backend Web Applications:** Built backend services and web APIs utilizing **Laravel**, establishing clean MVC application structures, routing logic, and client-server communications.
* **Server-Side Scripts & Services:** Integrated **Node.js** execution scripts to handle real-time data flow and asynchronous server events for interactive web utilities.
* **Frontend Design & Styling:** Engineered responsive web interfaces with **HTML5**, **CSS3**, and **JavaScript**, ensuring cross-browser stability and dynamic user interactions.

## About Palmas Montecarmelo SA

**Palmas Montecarmelo SA** is an agro-industrial enterprise located in Barranquilla, Atlántico, Colombia. The company operates across agricultural production, logistics, and supply chain management, utilizing custom internal software systems to streamline field operations and business intelligence.

---

## Technical Scope & Business Impact

At Palmas Montecarmelo SA, I served as Desarrollador de software, building native Android applications and developing the core web APIs that enabled real-time data connectivity with the company's enterprise web platform.

* **Native Android Application Development:** Engineered Android mobile applications to support internal field operations, data collection, and operational logging.
* **API & Web Service Implementation:** Built and deployed custom APIs to connect client mobile applications directly with the enterprise web platform, ensuring smooth data flow and server synchronization.
* **Backend Integration with C# & Visual Basic:** Maintained and expanded server-side web modules using **C#** and **Visual Basic**, supporting legacy infrastructure while extending platform capabilities.
* **Application Maintenance & Technical Support:** Managed post-deployment support, performance troubleshooting, and regular software updates for all deployed Android applications and backend integrations.

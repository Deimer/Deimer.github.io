## About ITEHL Consulting

**ITEHL Consulting** is a software development and technology consulting agency. The firm specializes in delivering custom web platforms, IT solutions, and native mobile applications for regional business clients and enterprise partners across Colombia.

---

## Technical Scope & Business Impact

At ITEHL Consulting, I served as a Junior Android Developer responsible for designing, developing, and publishing native mobile applications, as well as building supporting web services and managing database persistence.

* **Native Android UI & Functionality:** Developed consumer-facing application modules using **Java** and the **Android SDK**. Engineered dynamic UI screens with **XML Layouts**, custom view controls, and responsive styling to support diverse screen sizes.
* **Local Data Persistence with SQLite:** Designed relational schemas and managed client-side database caching using **SQLite**, ensuring stable application performance and local offline access.
* **Social Authentication & Location Services:** Integrated **Google Sign-In** and **Facebook Login APIs** for user onboarding, alongside **Google Maps API** for location-based features.
* **Backend Web Services Development:** Built and consumed custom **RESTful Web Services** using **PHP** and the **Laravel Framework**, establishing JSON endpoints for data synchronization between mobile clients and cloud servers.
* **Google Play Store Publishing:** Managed end-to-end application signing, APK compilation, store listing setup, and release management to the **Google Play Store**.

## About Ideamos Web

**Ideamos Web** is a digital agency and software development company focused on building custom web applications, e-commerce platforms, and tailored mobile solutions for commercial clients and businesses across Colombia.

---

## Technical Scope & Business Impact

During my initial engineering role at Ideamos Web, I worked as a Web and Mobile Developer delivering custom client projects, building core skills in web service architectures, relational databases, and native mobile development.

* **Backend Development & APIs:** Built server-side business logic and custom RESTful endpoints using **PHP** and the **Laravel Framework**, enabling secure data flow between web platforms and mobile applications.
* **Database Design & Management:** Designed relational database schemas and optimized data queries using **MySQL** to ensure data integrity and fast access speeds for client management systems.
* **Responsive Frontend Web Interfaces:** Developed dynamic web layouts and interfaces utilizing **HTML5**, **CSS3**, and **JavaScript**, delivering cross-browser compatibility and responsive styling.
* **Native Android App Development:** Created native mobile application prototypes and early commercial modules using **Java** and the **Android SDK**, managing client-side storage, layouts, and screen routing.
* **Version Control & Collaboration:** Maintained application codebases using **Git**, ensuring version tracking, clean code delivery, and collaboration across agency project workflows.

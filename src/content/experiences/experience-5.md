## About RobinFood

**RobinFood** (formerly MUY) is Colombia's leading foodtech pioneer and Latin America's largest ghost kitchen startup[cite: 1]. The company leverages proprietary software, automation, and cloud-kitchen network systems to deliver affordable, high-quality meal options at scale across Colombia, Mexico, and Brazil.

---

## Technical Scope & Business Impact

At RobinFood, I worked within the core mobile engineering team responsible for creating and optimizing consumer-facing delivery apps and internal kitchen execution software[cite: 1].

* **Android Architecture Components & Clean Architecture:** Built modular, high-performance features utilizing **Clean Architecture** paired with the **MVVM** pattern[cite: 1]. Enforced strict separation between data, domain, and UI layers using **AndroidX** standards[cite: 1].
* **Dependency Injection & Code Base Modularization:** Structured dependencies using **Dagger 2**[cite: 1] to ensure modular flexibility and clean object graph management. Refactored monolithic code structure into decoupled feature modules to accelerate build times and team throughput[cite: 1].
* **Asynchronous Execution & Data Streams:** Implemented **RxJava** and **Kotlin Coroutines**[cite: 1] to handle complex asynchronous operations, live order status polling, and background database syncing smoothly.
* **Hybrid & Cross-Platform Development:** Engineered cross-platform interface modules using **Flutter**[cite: 1] alongside native Android components, allowing rapid feature iteration across mobile platforms.
* **Network & Local Data Management:** Built robust REST networking integrations via **Retrofit**[cite: 1] with custom interceptors for session authentication and payload logging. Integrated **Navigation Component** for fluid in-app fragment routing[cite: 1].
* **Real-time Observability & Analytics:** Integrated **Firebase Analytics** for tracking user interaction events and **Firebase Realtime Database**[cite: 1] to push instantaneous order updates directly to store kitchen displays.

## About Ualá

**Ualá** is one of Latin America’s premier financial technology unicorns, providing an all-in-one ecosystem for digital banking, investments, loans, payment processing, and credit card management[cite: 1]. Serving millions of users across Argentina, Mexico, and Colombia, Ualá operates as a high-security, ultra-reliable mobile platform processing millions of financial transactions daily[cite: 1].

---

## Technical Scope & Business Impact

During my tenure at Ualá, I was part of the core mobile engineering team responsible for architecting and shipping mission-critical financial features, optimizing core app stability, and modernizing legacy codebases across high-scale distributed teams[cite: 1].

* **Declarative Financial Interfaces with Jetpack Compose:** Designed, migrated, and delivered modern UI screens utilizing **Jetpack Compose**, replacing legacy XML layouts to ensure smooth 60fps animations, seamless user flows, and strict alignment with Ualá's design system[cite: 1].
* **Clean Architecture & Reactive State Management:** Architected robust feature modules following **Clean Architecture** and **MVVM** principles[cite: 1]. Managed complex asynchronous states, payment pipelines, and real-time data streams using **Kotlin Coroutines**, **Flow**, and legacy **RxJava** streams[cite: 1].
* **Modularization at Scale:** Maintained and structured enterprise-level multi-module codebases, reducing inter-module dependencies, enforcing strict boundary isolation, optimizing incremental build times, and enabling parallel team velocity[cite: 1].
* **Dependency Injection & Networking:** Configured scalable dependency graphs using **Hilt**[cite: 1]. Constructed secure REST network layers with **Retrofit**[cite: 1], integrating custom interceptors for encrypted request payloads, token refresh mechanisms, and API performance tracking.
* **Local Data Persistence & Security:** Managed offline storage, user preferences, and sensitive client-side session tokens using **Room Database**, **DataStore**, and **AndroidX** security utilities[cite: 1].
* **Observability, Analytics & CI/CD:** Integrated **Firebase Analytics** to track user engagement funnels and **Crashlytics** for proactive crash monitoring[cite: 1]. Automated continuous integration and build distribution workflows using **GitHub Actions**[cite: 1].
* **Quality Assurance & Code Reliability:** Executed comprehensive testing strategies using **JUnit**, **Mockito**, and **Espresso** to maintain stability across critical payment paths and financial transaction pipelines[cite: 1].

## About Cloudnets S.A.

**Cloudnets S.A.** is a cloud solutions and custom software development enterprise. The company specializes in building enterprise web systems, cloud infrastructure integrations, and custom mobile applications for commercial clients across Latin America.

---

## Technical Scope & Business Impact

During my role at Cloudnets S.A., I worked as a Web and Mobile Developer delivering custom software projects, establishing core engineering practices in full-stack web architectures, database management, and native mobile development.

* **Backend Development & Web Services:** Built server-side business logic and custom RESTful endpoints using **PHP** and the **Laravel Framework**, facilitating smooth data synchronization between cloud servers and mobile applications.
* **Database Architecture & SQL:** Designed relational database schemas, indexes, and optimized queries using **MySQL** to ensure data integrity and reliable performance across cloud services.
* **Responsive Frontend Web Interfaces:** Developed dynamic web layouts and interfaces utilizing **HTML5**, **CSS3**, and **JavaScript**, delivering cross-browser compatibility and responsive styling.
* **Native Android App Development:** Created native mobile application prototypes and commercial modules using **Java** and the **Android SDK**, managing client-side storage, layouts, and screen routing.
* **Version Control & Software Workflows:** Maintained application codebases using **Git**, ensuring version tracking, clean code delivery, and collaboration across project teams.

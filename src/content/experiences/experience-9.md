## About Easy Solutions (a Cyxtera Business)

**Easy Solutions** (acquired by Cyxtera Technologies) was a global leader in total fraud protection, specialized in detecting, preventing, and mitigating electronic fraud across financial institutions and enterprise platforms. Their security suite protected over 100 million users and hundreds of financial institutions worldwide against mobile fraud, phishing, and identity theft.

---

## Technical Scope & Business Impact

At Easy Solutions, I worked as a Junior Android Developer within the mobile security division, focusing on building high-security SDK components, data protection utilities, and identity verification modules[cite: 1].

* **Cybersecurity & Data Protection:** Developed native Android modules enforcing strict user data protection, secure key storage, and encrypted transmission protocols to safeguard transaction telemetry against local and network eavesdropping[cite: 1].
* **Biometric & Gesture Recognition Libraries:** Created specialized Android libraries to complement biometric processing algorithms[cite: 1], integrating facial and gesture recognition mechanisms to authenticate financial application users safely[cite: 1].
* **Automated Unit Testing:** Authored comprehensive unit tests utilizing **JUnit** and **Mockito**[cite: 1] to validate core security algorithms, boundary conditions, and cryptographic utility functions before deployment.
* **Code Reliability & Quality Assurance:** Partnered with senior security architects to conduct code reviews, ensuring zero sensitive data leaks in log outputs and strict adherence to mobile OWASP security guidelines.
* **Version Control & Collaboration:** Managed codebases through version control workflows with **Git**, ensuring clean tracking of library distributions, security patches, and hotfixes across client integrations[cite: 1].

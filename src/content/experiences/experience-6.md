## About QuQo

**QuQo** is a digital B2B marketplace and supply chain startup designed to empower traditional mom-and-pop corner stores (tiendas de barrio) in Latin America. The platform directly connects small retailers with large consumer packaged goods (CPG) manufacturers, streamlining order management, inventory replenishment, and delivery logistics.

---

## Technical Scope & Business Impact

At QuQo, I served as a Mid-Senior (SSR) Android Developer focused on modernizing application architecture, improving real-time delivery logistics, and enhancing security across merchant workflows[cite: 1].

* **Architectural Modernization (MVP to MVVM):** Spearheaded the refactoring and migration of core codebase modules from legacy MVP architecture to **MVVM (Model-View-ViewModel)**[cite: 1], drastically reducing code coupling and improving state lifecycle stability.
* **Real-Time GPS Tracking:** Implemented background **GPS Location APIs** to track pilot users and delivery agents in real time[cite: 1], optimizing order routing, route verification, and delivery performance metrics.
* **Repository Pattern Implementation:** Architected a decoupled **Repository Pattern** layer[cite: 1] to centralize data sources (local databases, REST APIs, and Firebase), establishing clear separation between business logic and data access[cite: 1].
* **Asynchronous Streams & Reactive Programming:** Utilized **RxAndroid** to manage high-frequency data streams, background tasks, and event propagation asynchronously without blocking UI interactions[cite: 1].
* **Authentication & Backend Networking:** Integrated **Firebase Authentication** for secure social network login protocols[cite: 1]. Built robust REST service interfaces using **Retrofit**[cite: 1] for reliable order processing and catalog management.
* **Compatibility & Lifecycle Optimization:** Adopted **AndroidX** compatibility libraries[cite: 1] to ensure consistent application behavior across diverse Android device models and OS versions, managing complex **Android Lifecycle** components seamlessly[cite: 1].

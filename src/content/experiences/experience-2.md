## Technical Scope & Business Impact

As a Senior Android Developer at Apply Digital, I collaborated with cross-functional international teams (designers, product managers, backend engineers, and QA) to build scalable, production-ready native Android applications from the ground up and enhance existing enterprise codebases[cite: 1].

* **Modern Reactive UIs with Jetpack Compose:** Developed dynamic, fully accessible, and responsive visual interfaces using **Jetpack Compose**[cite: 1]. Standardized reusable UI component libraries according to strict design systems, reducing development time for new feature screens and optimizing UI rendering performance[cite: 1].
* **Robust Architecture & State Isolation:** Implemented **Clean Architecture** layered with **MVI (Model-View-Intent)** and **MVVM** patterns to guarantee complete separation of concerns[cite: 1]. Utilized **Kotlin Coroutines and Flow** to handle complex asynchronous operations, state mutation, and reactive data streaming safely across different threads[cite: 1].
* **Project Modularization:** Designed and maintained multi-module project structures to enforce dependency boundaries, isolate feature domains, speed up compilation times with build caching, and facilitate multi-developer workflows without merge conflicts[cite: 1].
* **Dependency Injection & Local Persistence:** Built and managed dependency trees using **Hilt**[cite: 1]. Architected secure local storage layers with **Room Database** and **DataStore**[cite: 1], ensuring seamless offline capabilities and persistent state caching[cite: 1].
* **Networking & Integration:** Connected complex mobile clients to cloud backend infrastructures via **Retrofit** and **OkHttp**[cite: 1], implementing dynamic request interceptors, token refresh flows, and centralized error-handling strategies.
* **Testing & Quality Assurance:** Authored comprehensive unit, integration, and UI test suites using **JUnit**, **Mockito**, and **Espresso**[cite: 1] to ensure stability, prevent regressions, and enforce solid test coverage across critical user paths[cite: 1].
* **Observability & Dynamic Features:** Configured **Firebase Analytics** to track user behavior metrics, **Crashlytics** for real-time exception reporting[cite: 1], and **Remote Config** for feature toggling and A/B testing[cite: 1].
* **CI/CD Automation:** Set up and maintained continuous integration pipelines using **GitHub Actions** and **GitLab CI**[cite: 1], automating static code analysis, unit testing validation, and automated deployment to internal testing channels and the Google Play Store[cite: 1].
